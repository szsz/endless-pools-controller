Display Brightness

Changes are applied immediately and persisted in LittleFS (/settings.json).

Swim Machine

Workouts run normally (timers, display, run screen) but no commands are sent to the machine, and a workout can start even when no machine is detected. Use this to test without driving the pool.

Display Mode

Big shows large remaining metres and time for the current swim, its name underneath, and only the next two swims at the bottom. Preview both layouts offline by opening viewer/hub75.html on your computer.

Screen Saver

The screen stays on while a workout is running. The countdown starts when a workout ends (or at boot if none is started). Set to 0 to keep the screen always on.

Upload Files to LittleFS

Files are written under the LittleFS root. Subfolders will be created as needed.
